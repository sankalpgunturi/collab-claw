collab-claw 🦞

Pair-program with one Claude across multiple laptops.

Get started View on GitHub

What is it?

collab-claw lets a group of teammates collaborate inside a single Claude Code session. The host runs Claude as usual; teammates connect from their own laptops via a small CLI and see the conversation live. Their prompts get prefixed with their name ([Alice]: …) and delivered to the host's Claude as if they had typed them locally.

One Claude, many humans

The host runs Claude Code; joiners install a thin CLI. No second Claude session, no second bill.

Local-first

The relay runs on the host's laptop over LAN. No accounts, no servers, no signup.

Cross-network when you want it

collab-claw expose wraps a Cloudflare quick tunnel — opt-in, off by default.

Token-scoped pairing

Joiners are explicitly approved by the host. Member tokens are revoked on kick or leave.

Persistent transcripts

Every room is logged to ~/.collab-claw/log/<roomId>.jsonl. Replay with collab-claw history.

MIT-licensed

Fork it, ship it, change it. The code is small (~2k LOC), readable, and has zero runtime deps.

1.Install

You need Node.js ≥ 18 on every machine. The host also needs Claude Code.

# npm:
npm install -g collab-claw

# Homebrew (macOS / Linux):
brew tap sankalpgunturi/tap
brew install collab-claw

2.Host a room

Install the plugin in Claude Code once:

/plugin marketplace add sankalpgunturi/collab-claw
/plugin install collab-claw

Then start a room from any Claude Code session:

/collab-claw:host

You'll get a join URL like http://10.0.0.42:7474#secret=… to DM to teammates. Keep working with Claude as you normally would — joiner prompts arrive as [Name]: <text> notifications.

3.Join a room

collab-claw set-name Bob      # one-time
collab-claw join <url>

You'll see a TUI with the host's transcript scrolling. Type a prompt, hit Enter, the host's Claude responds. Press Ctrl-C to leave.
