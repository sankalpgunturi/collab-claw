CollabClaw — logo concepts

Honest disclaimer: hand-writing organic-shape SVGs isn't something I'm good at. The options below are my best attempts at the "two claws meeting" composition you sketched. For a production-quality logo I'd recommend either an open emoji set (see "Alternative sources" at the bottom) or a real designer. Treat this page as a sketchpad — screenshot whichever option you like, or copy the inline SVG source into docs/logo.svg directly.

Option A — Two claws (geometric, current direction)

Two mirrored crab-claw silhouettes facing each other. Coral fill, dark outline, soft highlight. The most "matches the reference Shutterstock" attempt.

A1 — Mirrored crab silhouette

Most reference-faithful but the most code (and the most chances for it to look off). Editable: change fill="#E55934" for the colour.

A1 — on dark

Same shape, dark background, lighter outline. Useful to check contrast for the GitHub social card.

Option B — Two abstract crescents

More iconographic, less literal. Two opposing C-shapes hinting at a pincer. Looks better at small sizes (favicon).

B1 — Stylized "C"s

Each side is a simple bow shape with a pincer-notch. Reads as "claws meeting" without literal anatomy. Scales well.

B2 — Pac-Man pair

Dead simple: circle minus wedge, mirrored. Reads instantly. Probably too generic.

Option C — Just the emoji

Skip the SVG entirely. 🦞 renders consistently on every modern OS, and is what many GitHub READMEs already do for branding.

🦞

C1 — Lobster emoji

Use as inline character in the README H1: <h1>CollabClaw 🦞</h1>. Pros: free, professional-looking, scales perfectly, zero maintenance. Cons: looks slightly different on macOS vs Windows vs Linux.

🦞 🤝 🦞

C2 — Two lobsters shaking

Reinforces the "collaboration" theme. Probably too much for a header but cute for social cards.

Alternative sources (recommended)

If you want something polished without hiring a designer, these emoji libraries ship as open-licensed SVGs and have professional lobster/crab claw graphics:

  • OpenMoji 🦞 — CC-BY-SA 4.0. Download the SVG and commit it as docs/logo.svg. Attribution: "Logo: OpenMoji 1F99E (CC BY-SA 4.0)" in the footer.
  • Noto Emoji — Apache 2.0. Google's open emoji set. Lobster at svg/emoji_u1f99e.svg. Most permissive license.
  • Fluent UI Emoji — MIT. Microsoft's set; "Lobster" in 3D and flat. Visually closest to the Shutterstock reference you sent.

Any of these will look better than my hand-written attempts above and cost nothing.

How to use what you pick

Whichever option you like:

  1. Right-click the SVG → "View Source" (or copy the inline source from this file).
  2. Replace the contents of docs/logo.svg.
  3. The README and Pages site both reference docs/logo.svg — no other changes needed.

Or, if you'd rather screenshot:

  1. Open this page in a browser at full window size.
  2. Zoom in (Cmd/Ctrl + several times) until the option you like fills the screen.
  3. Screenshot just that option, save as PNG, then convert to SVG via vectorizer.ai or similar.
